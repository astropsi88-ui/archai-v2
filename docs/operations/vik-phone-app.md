# Устанавливаемый личный клиент Вика

Owner-поручение 13 октября 2026: мини-приложение на телефон для прямого личного разговора вне Telegram.

## Размещение и безопасность

Статический клиент `public/vik/` работает на `https://vik.iarch.ai/vik/` и `https://iarch.ai/vik/`. Первое имя обслуживает отдельный nginx virtual host, но оба имени ведут на тот же сервер и backend. Это независимость от Telegram, а не независимый инфраструктурный резерв.

Секретная фраза проверяется существующим `owner/auth`. Клиент не сохраняет фразу и не помещает её в URL, историю, аналитические системы или кэш. Cookie — существующая HttpOnly/Secure/SameSite=Lax сессия, отдельная для каждого домена. Перед восстановлением истории и отправкой проверяется существующий owner-only GET `owner/secret-rotation` без изменения секретов. При истечении сессии приложение возвращается к личному входу и не отправляет текст от публичного посетителя.

Nginx `vik-phone-nginx.conf` допускает только ожидаемые API-пути. Для нового домена проверяются точный Origin и метод до передачи канонического Origin существующему backend; внешние Origins и POST без Origin отклоняются. Внутренние Telegram API не открываются.

Service worker имеет scope `/vik/` и кэширует только публичную оболочку. История и API-ответы не кэшируются. Черновик хранится локально в браузере; автоматической отправки после возвращения сети нет. При неоднозначном результате POST клиент сверяет историю и не делает автоматический повтор. Сервер пока не принимает idempotency key клиента: абсолютная защита от повторов на уровне транспорта не заявляется.

## Установка

- Android Chrome: «На телефон» либо меню → «Установить приложение»/«Добавить на главный экран».
- iPhone Safari: «Поделиться» → «На экран Домой» → «Добавить».
- Встроенный браузер Telegram для установки не использовать.

Для получения ответов нужны интернет и доступный сетевой маршрут. Проверка из российской мобильной сети владельца выполняется с её телефона; проверка с сервера не подтверждает отсутствие сетевых блокировок.

## Выкладка

Стандартный `npm test`, commit → push main → существующий `deploy-archai-v2.sh`. В корне старого vik virtual host находится symlink `vik -> ../archai-v2/current/vik`. Маршруты музыки и preview сохраняются. Конфигурацию предварительно копировать в бэкап и проверять `docker exec nginx-proxy-manager nginx -t`. Graceful reload nginx сохраняет master PID и активные запросы; Telegram, PM2, Docker daemon, backend и runners не перезапускать.

Технические источники требований установки: [MDN — Making PWAs installable](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable). PNG-иконки получены из существующей SVG-иконки Вика без платной генерации.
